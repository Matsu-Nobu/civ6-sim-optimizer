# セーブ解析で読める項目（civ6-savegame-parser v0.4.0 の README より。10/19 に Rust の `optimizer/src/save/` に移した）

読める: マップ（地形・地物・資源・改善・川・道路・所有者）、都市の人口・働かせているタイル・専門家・食料の蓄積・
生産中のもの・生産の蓄積・生産キュー・建造物・区域、研究/社会制度（完了・ブースト・進捗・研究中）、政体・政策、
ゴールド（所持・収支）、信仰・パンテオン、ユニット（位置・労働者のチャージ）、偉人ポイント、時代スコア、
リプレイグラフ（科学・文化・ゴールドの毎ターン推移）。

読めない（ゲームが実行時に計算）: 産出量、住宅、快適性、成長に必要な食料、余剰。
→ シミュレータで計算し、次ターンのセーブと比べることで精度確認に使える。

関連ツール: Civ6EGRM（Python, オートセーブの監視コピー）、Civ VI Replay（SourceForge）。

## 実セーブでの検証（2026-10-05, data/saves/multi T22–T31, BBG 7.5.1 / BBG Expanded 2.1 / BBM 1.39.5）

使えた: 研究/社会制度（完了・ブースト・進捗・研究中）、政体・政策、ゴールドと収支、プレイヤー単位の毎ターン産出
（食料/生産/ゴールド/科学/文化）、都市の人口・働かせているタイル・生産中のものと生産の蓄積、建造物、区域、
ユニット、生産したユニット数の累計、偉人ポイント、時代スコア、MOD名（セーブ内の文字列から）。
ターン間で値の増え方が一貫している（例: ローマの商業ハブ 0→18.6→29.4、ゴールド収支と所持金の推移）。

壊れている: 都市の食料の蓄積（全都市が 38517.5 で固定 → オフセットずれ。BBGか版の違いが原因の可能性）。
怪しい: 生産キュー（同じプレイヤーの全都市で同じ並び。キューではない可能性）。
人間の判別: human フラグは全員 false（パーサーの問題）。名前が入っているプレイヤーが人間（player 0 "vd" = ユーザー、他はAI）。

スクリプト: save_export/inspect.js（全体）, save_export/players.js, save_export/timeline.js <dir> <playerId>（ターンごとの推移）
実行: export PATH=~/civ6-sim-optimizer/tools/node-v22.11.0-linux-x64/bin:$PATH

## パーサーの修正（ローカル）

third_party/civ6-savegame-parser/src/internal/parse-city-history.ts の readLpStrings で、読む範囲がデータ末尾を超えて
落ちていた（首都を建てたターンのセーブで発生）。範囲をデータ長に収めるよう修正してビルドし直した。
save_export/events.js <dir> <playerId> でターンごとの産出と出来事（研究・社会制度・政策・ユニット・建造物・区域・都市）を出せる。
