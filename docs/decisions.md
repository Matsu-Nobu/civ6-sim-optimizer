# 記録の範囲

この文書には、プロジェクトで決めたことを、理由と経緯とあわせて記載する。次のセッションの Claude が、同じ議論を繰り返さず、あなたの指示に沿って作業を続けられることを目的にしている。決めた人の列の「あなた」はあなたが決めたこと、「合意」は Claude の提案にあなたが合意したことを表す。反映先の列には、その決定が今どこに効いているかを記載する。

決定は、作業の進め方、シミュレータ、探索、作戦と条件、PC の環境の 5 つに分けて並べる。各表の中は日付順である。
