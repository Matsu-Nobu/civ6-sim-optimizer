# 進め方の全体

対局の分析は、次の順に進める。各段階で使うプログラムとファイルは [artifacts.md](artifacts.md) にある。

| 段階 | すること |
|---|---|
| 記録の取り込み | 対局のオートセーブから、毎ターンのプレイヤーの状態を書き出す |
| 対局データの作成 | 書き出した記録、地図、ゲームのルールを、シミュレータが読む 1 つのファイルにまとめる |
| 再現の確認 | 自分の選択をシミュレータでなぞり、産出が実際の対局と合うかを比べる |
| 探索 | 条件を付けて、点数が最大になる計画を探す |
| 比較 | 最良の計画と自分のプレイを比べ、レポートにまとめる |

# 記録の取り込み

ゲームは毎ターン、オートセーブを残す。セーブ解析のプログラムが、各ターンのセーブから都市・タイル・研究・ユニットなどを読み出す。

ゲームのルールは、mod を適用した後の状態をゲーム自身がデータベースに書き出すので、それをそのまま使う。

# 再現の確認

シミュレータが自分の選択をなぞった結果と、実際の対局の産出を、ターンごとに比べる。差が大きいときは、どのターンのどの都市から離れたかを調べて、シミュレータを直す。

シミュレータが計算できない出来事は、記録から外の情報として与える。ひらめき、使節、時代の変わり目、他のプレイヤーが建てた遺産と取った偉人、味方から受け取った金とユニットがこれにあたる。

# 計画の点数

計画の点数は、全都市の毎ターンの食料と生産を、評価するターンまで足した値である。食料と生産は、人口と生産力の伸びをそのまま表すので、内政の強さの目安にしている。

科学・文化・軍事は、点数ではなく条件で扱う。例えば「T44 までに城と傭兵を終え、将軍を 1 人取る」のように、決めたターンまでに必要なものを与え、足りなければ大きな罰点を引く。騎乗兵の数のように多いほど良いものは、1 体ごとの加点で扱う。

# 探索

探索プログラムは、計画を 1 つずつ変えて点数を比べ、良くなった変更を残す。一つの決定を変えたら、その後ろの決定をすべて詰め直してから比べる。こうしないと、序盤を変えたときに後ろの計画が噛み合わず、良い変更でも点数が下がって捨てられてしまう。手法を比べた結果は [reports/search_methods.md](reports/search_methods.md) にある。
